## 🚀 Projetos em destaque (Level 3)

### 🐟 AquaVivo — Sistema de Gestão para Piscicultura
Plataforma completa para gestão de piscicultura cobrindo todo o ciclo produtivo: tanques, lotes, análise de água, manejos, transferências e despesca, além de estoque, custos e financeiro.

**Diferenciais:** índice de saúde, previsão de despesca via curvas de crescimento, calculadora inteligente de ração e modo offline para uso em campo.

`Spring Boot 3` `Java 17` `PostgreSQL` `React` `TypeScript` `Tailwind` `Framer Motion`

### 🛒 Madex — Sistema PDV
Plataforma de Ponto de Venda em produção, redesenhada com estética premium em dark mode, ícones coloridos e microinterações com Framer Motion. Foco em performance no caixa e experiência do operador.

`Spring Boot` `React` `TypeScript` `PostgreSQL`
